# EasyMic 中文文档

EasyMic `0.1.3-exp.6` 为 Unity 提供基于 miniaudio 的外部音频采集和播放传输层。可选的 EasyMic APM 扩展增加了需要授权的音频处理和实验性定向拾音能力。它适用于需要麦克风输入、自定义 PCM 播放、音频处理和诊断能力的交互式应用。

APM 产品信息请参阅 [EasyMic APM 产品网站](https://eitanwong.github.io/easymic-apm-site)。
